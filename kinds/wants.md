# 走法：想要的选项（wants）

**抓什么**：不同的玩家**想做、但作品没给**的东西。不是 bug：代码照设计做了，只是这一类玩家走到这里，发现他最想按的那个按钮不存在。

三种缺口：
- **缺的选项**：选择点上没有他想选的那一个（想拒绝但不撕破脸、想赊账、想问一句再决定、想两个都不帮）。
- **缺的设置和便利**：他需要的开关作品没给（字幕、字号、改键、跳过已读、对话回看、手动存档、关掉限时、难度）。
- **缺的反应**：他做了一件有意思的事，作品没有任何回应（送了一件特别的东西，对方说的是默认台词；守了一条规矩，没人承认）。

这一种走法要画像：每个画像是一种"想要"的来源。画像越杂，找到的缺口越全。

依据：这是工具包的目的之一（模仿不同的玩家，看他们想要什么我们没做的）。走法本身是整理出来的，没有照搬的出处；"扮成这类玩家会想要什么"是推断，所以每一条都要写清**是谁想要、凭什么说他想要**，让{{OWNER}}自己判断值不值得做。

## 先列两张表（写进草稿）

有作品地图就从它的「选择点」和「设置和便利」两张表起步，回原文件核对；没有地图就自己列。

1. **选择点表**：玩家每一个能做选择的地方。| 在哪条线、哪一步 | 现在有哪些选项（按钮上的字，键和原文）| 每个选项通到哪 | 出处 |
   别漏了"没有按钮的选择"：卖不卖、给不给、来不来、等不等、存不存档，也是选择。
2. **设置和便利表**：作品给了哪些。| 是什么 | 在哪改 | 默认值 | 出处 |

## 怎么走

**1. 选择点 × 画像**：每个选择点，每个画像问一遍：

| 这个玩家此刻最想做什么 | 选项里有吗 | 没有的话，他只能怎样 |
|---|---|---|
| 照画像的「怎么玩」「盯着」来推，写一句他的理由 | 有 / 没有 / 有但要先满足他不知道的条件 | 选一个违心的 / 干等 / 退出不选 / 读档 |

- 善恶画像最容易出缺口：好心人想帮但只能"买"或"不买"；守规矩的人想拒绝又不想害人；侠盗想帮人又不想留把柄。
- 动机画像：按人设选的人，他的人设在这一步没有对应的选项；对着干的人想拒绝，没有拒绝。
- 玩法画像：点得飞快的人想要"不再问我"；马虎的人想要"撤回"。

**2. 设置和便利 × 画像**：每个画像（处境画像优先）问：他要玩下去，需要哪个开关？表里有吗？
- 读字吃力的人：对话回看、不自动翻页、字号。
- 按不住键的人：长按换成点按、关掉连打、关掉限时。
- 每次只玩几分钟的人：随时存档、随时暂停。
- 二周目的人：跳过已读、跳过教学。
- 作品是模组时：只查模组加的东西；宿主已经给的设置，模组的界面认不认。

**3. 缺的反应**：把画像会做的"有意思的事"列出来（送特别的东西、守一条规矩、用怪办法过关、一直拒绝、一直帮同一个人）。每件事查：作品有专门的回应吗，还是落到默认台词、默认结局？只报玩家**明显在期待回应**的那些。

**4. 数一数**：同一个缺口，这一组里有几个画像都想要？写上。想要的人越杂，越值得做。

## 算不算一条

报：
- 这类玩家照常理会想要，而且作品里**同类的地方给了**（别的角色能赊账，这个不能；别的选择点能拒绝，这个不能）。
- 没有它，这类玩家只能做一个**违背他玩法**的选择，或者被惩罚。
- 没有它，这类玩家**玩不下去**（处境画像的设置类缺口）。

不报：
- 题材和设计明显不想给的（恐怖游戏里想要"无敌模式"；设计稿写明"这里就是没有回头路"）。写进「查过、没问题的」，一句话。
- 只是"有了更好"，说不出哪一类玩家、在哪一步、因为什么想要的。
- 宿主游戏该做的事（作品是模组时），除非模组改了那一块。

## 定把握

- **【确定没有】**：你把这个选择点的选项列全了（带出处和原文），也全作品搜过了有没有别的入口。写上搜了什么。
- **【可能没有】**：选项是代码里拼出来的、或者由宿主游戏提供，读代码列不全。写清哪里看不到。
- "他想要"是推断，永远不标【确定】：把理由写出来就行。

## 报告里多写什么

缺口写进报告的「想要但没有的」一节，编号 W1、W2……。每条：

```
### W1 〈一句话：谁，在哪，想做什么〉
- 谁想要：〈画像编号和名字〉（这一组里还有：…也想要）
- 在哪一步：〈线、回合、选择点〉
- 他想做什么、为什么：一两句，照画像说
- 现在有的选项：「…」「…」（`文件:行` 原文）
- 没有它，他只能：〈选违心的 / 被惩罚 / 玩不下去 / 干等〉→ 后果（`文件:行`）
- 作品里别处有没有同类的选项：有（在哪）/ 没有
- 把握：【确定没有】搜过：… ／【可能没有】看不到：…
- 可以怎么加：一两种，写清各自要动什么（一个按钮和一句回话；一个设置项）
```

索引一节照常写：W 条目引的是"现在有的选项"那几行。
开头放一张小表：缺口｜几个画像想要｜没有它会怎样。按"想要的画像多、后果重"排。
