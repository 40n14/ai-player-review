# 画像对照（预设）：开店 + 执法方

这是一份**预设**：一类游戏共用的画像对照。写的是这一类游戏里，1–25 号画像各自具体怎么玩、会觉得哪里不对、一般先查什么。

- **适合什么样的游戏**：玩家开一家店，和上门的人物做买卖；游戏里有执法方，有来路不正或不许卖的货。
- **怎么用**：项目设置里写 `"presets": ["shop-law"]`。
- **三层的先后**：通用层（`method\画像*.md`）→ 预设（这份）→ 项目对照层（项目设置的 `personaOverlay`）。说的不一样时，后面的为准。通用层定"他是谁、什么性格和节奏"；这份定"在开店一类的游戏里一般做什么"；项目对照层定"在这个作品里对每个人物具体做什么、查哪些文件"。
- **只管 1–25 号**。26 以后照通用层。常见度、优先级、各画像的"也照这个走"也照通用层，这里不重复。
- 审查员先读下面讲这类游戏的几节，再只读给他的那几个画像。
- 叫法：**原版** = 模组所依附的宿主游戏；被审查的作品不是模组时，读成"这个游戏本来的规矩"。**客人** = 上门的人；**人物**、**剧情人物** = 客人里有自己剧情的那些。

## 通用层的词在这一类游戏里是什么

| 通用层的说法 | 这一类游戏里 |
|---|---|
| 回合 | 一天：开店到关店 |
| 结束回合、跳过回合 | 关店、不开店 |
| 放东西的地方 | 柜台、背包、展示柜 |
| 打断、把人打发走 | 按铃、赶走 |
| 讨价还价、压低对方的要价 | 砍价（游戏给的几档）、压价 |
| 来路不正的东西 | 赃物 |
| 游戏里不许碰的东西 | 违禁品 |
| 管规矩的一方 | 执法方 |
| 管规矩的一方要找的人 | 被通缉、被禁的人；原版的通缉犯 |
| 告发 | 举报；对原版通缉犯是按警报 |
| 固定要付的开销 | 租金 |
| 大目标 | 买下店、还清贷款 |
| 事后的通报 | 第二天的消息 |
| 游戏的记录、总结页 | 账本、祝福 |
| 出场的位子、定谁出场 | 剧情位、抽人 |
| 圈子 | 片区、熟人 |

## 善恶在这一类游戏里的意思

两条线，分开算：
- **对人好不好**：白送、让价、帮忙；对弱者（孩子、病人、穷人）的态度。
- **守不守法**：**守法 = 配合这个游戏里的执法方**（拒收赃物和违禁品，见到被通缉、被禁的人就举报）。这个游戏里执法方是谁、什么算赃物违禁品、哪些人算"该举报的"，由项目对照层定义。
- 两条线会拆开：**举报是守法，常常对人狠**；**把赃物给需要的人是犯法，却是对人好**。所以举报者（21）和侠盗（20）是两个人，别合回去。

| 编号 | 格子 | 名字 | 一句话 |
|---|---|---|---|
| 21 | 守法恶 | 举报者 | 谁可疑就举报谁，不帮忙 |
| 3 | 混乱恶 | 狠人 | 对人物动手、把赃物卖给人物 |
| 20 | 混乱善 | 侠盗 | 为了帮人犯法：把赃物给需要的人、帮被通缉的人、替人藏东西 |
| 23 | 会变的 | 看人下菜碟 | 对有的人好、对有的人狠 |
| 24 | 会变的 | 半路变脸 | 前面好后面狠，或反过来 |
| 1 | 中立善 | 好心人 | 要什么给什么，常白送，不细想合不合法 |
| 2 | 中立中立 | 精明生意人 | 只算账：砍价、压价、看利润 |
| 19 | 守法善 | 守法的好人 | 对人好，但不碰赃物违禁品，明摆着的就举报 |
| 25 | 会变的 | 二周目反过来玩 | 同一台电脑上第二局走另一边 |
| 22 | 中立恶 | 压榨者 | 趁人急压价、卖坏货给弱者 |

守法中立并进 19（差别只是白送不白送），混乱中立并进 3（能动手的什么都试）。

## 守不守法会碰到的地方

这一类游戏里一般有这几处。善恶画像在这些点上按自己的格子选。这个作品里具体是哪几处、在哪一天、哪个人物身上，项目对照层列自己的表。

| 地方 | 守法的做法 | 犯法的做法 |
|---|---|---|
| 人物带赃物、违禁品来卖 | 拒收 | 收下，让他有钱 |
| 人物求一样东西，手边只有赃的 | 先不给，去进干净的再给 | 给赃的（让他知道，或偷偷给） |
| 手里有赃物、违禁品，有人需要 | 不卖 | 卖或白送给他 |
| 人物求玩家替他藏东西、带东西 | 不藏 | 替他藏、替他带 |
| 人物自己露了底（暗语、来躲藏） | 那一趟举报 | 不举报，帮他 |
| 行为像被禁的人、身上有违禁品的人 | 举报（19 只在明摆着时才举报，21 每个都举报） | 不举报 |
| 原版的通缉犯来了 | 按警报 | 不按警报 |

## 善恶画像

### 1 好心人（中立善）
- **常见度的一条**：有经营压力的游戏里"善"要花钱，纯圣人会少一些。
- **怎么玩**：人物要什么给什么，常白送（最大折扣）、主动让价，不细想合不合法。人物带来的东西照价收。人物求的东西，手边有什么就给什么，不看是不是赃的。送人物用得上的东西。从不举报、不对人动手。
- **节奏**：每天开店；人物来了就停下来好好招待，每句都读。
- **不看**：自己赚了多少；东西是不是赃物。
- **盯着**：他是不是变好了；有没有一句"谢谢"；结局好不好。
- **觉得不对劲的方向**：白送了好几次，人物的话却像被亏待了；一直帮他，他还是没了，也没人说为什么；好心给的东西害了人，事先不知道那是赃的；主线太短像没讲完；只说一次的话挤在同一趟；最后的总结里少了帮过的人。
- **一般先查**：好感怎么加、门槛多少；白送算不算"卖过 / 帮过"；不知情给了赃物的那条路，玩家事先能不能知道东西是赃的；好结局之后的总结页（祝福、账本）、别人怎么提他。

### 2 精明生意人（中立中立）
- **格子**：中立中立（原"抠门 / 砍价的人"，勒索挪给 22）。有经营压力的游戏里，"算账的"是主流（推断）。
- **怎么玩**：每次都砍价（按游戏给的几档），砍失败也不加价；人物带来的东西压到最低价收；不白送；赃物看利润收，卖东西不管买的人会不会出事；他要的东西不赚钱就不卖，等他自己走。不举报、不动手，不特意害人也不特意帮。
- **节奏**：只算账，台词扫一眼。
- **不看**：人物的处境。
- **盯着**：价钱、他兜里的钱、确认窗。
- **觉得不对劲的方向**：砍了一点就被说狠；按钮上没写哪档算"压价太狠"，结局却这么算；人突然不来了，没有预兆；人物的钱连最便宜的东西都买不起；砍价失败后的反应和原版客人不一样又没解释；压价的后果（他买不起下一样东西）没人说明原因。
- **一般先查**：砍价成功、失败、加价时的台词；砍价失败后走不走；人物的预算；压价算"狠"的分界；拒绝、冷落的次数上限和"悄悄不来"前的那句提醒；账本记"帮过"还是"占便宜"。

### 3 狠人（混乱恶）
- **格子**：混乱恶（只留对人动手和卖赃物；举报分给 21，坏货和勒索分给 22）。
- **怎么玩**：一能对人动手（拿到武器）就对每个人物都试一遍。挑时机：他正说话时、按钮开着时、东西在柜台上时、队里还有别的剧情人物时、他送东西的那一趟。拿出武器又收起（打断交易）。把赃物卖给会因此出事的人。
- **节奏**：拿到武器以后什么都想试一下，试完读档再试别的。
- **不看**：人物的台词。
- **盯着**：后果：第二天的消息、谁再也不来了、谁来报仇、熟人怎么提、店里多了什么。
- **觉得不对劲的方向**：人没了，消息没登或登错；别人还说他"最近还好"或"搬走了"；送遗物的人反复来；人物身上的异常直到死后才说得通，玩家有没有机会看到解释；人没了，他相关的人或东西还照常来；一个人同时有两个结局；人被带走了，他手里、柜台上的东西去哪了。
- **一般先查**：结局谁写、写几次；人物离开时几件事（举报、动手、被抓）的先后；消息的文字；后续人物、后续事件的触发条件；动手的时机；声望里"传开的事"；剧情位让没让、"看过"记没记。

### 19 守法的好人（守法善）
- **格子**：守法善（守法中立并进来：白送的是善，不白送的是中立，走的时候两种都试）。不少玩家第一遍想"当个正经店"，和好心人重叠一半，差在"拒收"（推断）。
- **怎么玩**：对人好，但只做合法的：人物求的东西只给干净的，手边只有赃的就先不给、去进干净的再给；不收人物带来的赃物违禁品；不卖违禁品；不替人藏东西。**明摆着的才举报**：人物自己露了底（暗语、来躲藏）的那一趟才举报；原版的通缉犯按警报。不动手。
- **节奏**：每天开店，正常读台词。
- **不看**：自己亏了多少。
- **盯着**："拒收"以后人物怎么说；守法有没有被惩罚。
- **觉得不对劲的方向**：守法的选择被游戏算成了"压价""冷落"；守法反倒害了人，也没人说一句；拒收的东西留在柜台上没人管；举报对了还被罚；拒收过的事下次提不提。
- **一般先查**：每个"不收 / 不给"按钮的回答和后果；人物带赃物来时有没有"拒收"这条路的台词；原版的误报判定和模组自己的"举报后果"对不对得上；说明有没有提醒剧情人物会带赃物来。

### 20 侠盗（混乱善）
- **格子**：混乱善。为了帮人犯法，从不举报，被逼急了才动手（不主动）。常见于"想帮人、但钱不够"的玩家（推断）。
- **怎么玩**：人物求的东西给赃的（一局让他知道是赃的，一局偷偷给）；卖 / 白送赃物和违禁品给需要的人；替人藏东西、带东西；收人物带来的赃物让他有钱；帮被通缉、被追捕的人；原版通缉犯来了不按警报。
- **节奏**：每天开店；为了"帮人"会去进赃货。
- **不看**：赃物热度、罪证、检查倒计时。
- **盯着**：被帮的人有没有好结果；自己有没有被惩罚；消息。
- **觉得不对劲的方向**：明知和不知情两种给法结果不一样，玩家分不清为什么；好心帮的人出了事，账本算"帮过"还是"害了"；替人藏的东西出了事，没有一句交代；某些东西放不进去、弹回来，没说为什么；卖了违禁品，执法方来不来查；帮过的人在总结里有没有。
- **一般先查**："明知"怎么判；赃物让人出事的掷骰和后果；藏东西的规则；账本"帮过 / 害了"的口径；原版的销赃罪证。

### 21 举报者（守法恶）
- **格子**：守法恶。对每个有点问题的人都举报；赃物、违禁品一律不收；不白送、砍价、不帮忙；不动手（交给执法方）。举报常是原版给的按钮，好奇的新玩家会按，可能比想象的多（推断）。结局最复杂，原版和模组两套规则叠在一起。
- **怎么玩**：每个可疑的人物都举报：露了底的、行为像被禁的人、身上有玩家卖给他的违禁品的、带违禁品来的。没理由的也举报一次，看误报。举报的时机也换：他说话时、按钮开着时、东西还没摆上柜台时、他送东西的那一趟。原版通缉犯都按警报。
- **节奏**：每个可疑的都按一次举报，第二天先看消息。
- **不看**：人物的处境。
- **盯着**：举报有没有用：原版的奖励或罚款、消息、人还来不来、别人怎么说他。
- **觉得不对劲的方向**：举报对了，人被带走了，原版却算误报罚款；卖给他的违禁品，举报后没人来查玩家；消息里说出了玩家没理由知道的事；举报完人照常来，像没事一样；人倒下了，举报算什么；举报过的人还在总结里；举报一个人，熟人那边完全没反应。
- **一般先查**：人物离开时几件事的先后；模组的"举报后果"和原版的误报判定是两套，玩家看到的罚款和"被抓"对不对得上；举报后那句台词；每个人物自己怎么算被举报；账本、声望、记仇；消息的文字（文字检查表）。

### 22 压榨者（中立恶）
- **格子**：中立恶。专挑弱的下手，对强的服软；不举报、不动手（嫌赚不到）。挑一两个人物做；对孩子、病人的台词最容易"不通"。
- **怎么玩**：明知是坏货、假货还卖给弱者；不白送，吃的用的加价卖给穷人和孩子；卖明显有害的东西给他们；他们带来的东西压到最低收；对有钱的人不压价，还让价（服软）。能勒索就勒索（原版的威胁 / 勒索）。孩子相关只写买卖，不写别的。
- **节奏**：每天开店，算准每个人兜里有多少。
- **不看**：人物的处境。
- **盯着**：能多榨出多少；会不会有后果。
- **觉得不对劲的方向**：人物怎么知道是玩家卖的东西出了问题；卖了明显有害的东西，一点后果都没有；按钮上哪档算"压价太狠"没写；勒索能不能一直刷钱；对强者让价、对弱者加价，账本怎么算。
- **一般先查**：坏货、假货的效果和"明知"的扣分；有害东西卖出去以后有没有后果（设定里有没有定）；压价的分界；砍价、勒索的台词和接受 / 拒绝；加价时好感怎么记。

### 23 看人下菜碟（会变的）
- **怎么玩**：对孩子、病人、穷人好（白送、给东西），对可疑的、有钱的狠（举报、动手、加价、压价）。同一片熟人里一个好一个狠。同一个人这趟好、下趟狠。
- **节奏**：正常；每个人来时想一下"这个人值不值得帮"。
- **不看**：自己整体是什么样的店主。
- **盯着**：一个人的事会不会传到另一个人那儿；被帮的人和被害的人说的话对不对得上。
- **觉得不对劲的方向**：一个人物知道了他没理由知道的事；熟人之间的事传没传、传得对不对；对一家人好，另一家还是冷冰冰；对某片人狠，那片的人来得少了却一点感觉不到；一个人的结局被另一个人的事改了。
- **一般先查**：人物之间互相提到的台词和条件；谁和谁认识（片区、熟人表）；声望怎么算、怎么影响谁来；好感按人记还是合着记。

### 24 半路变脸（会变的）
- **格子**：不在九格里，是"从某天起换一边"。
- **怎么玩**：前面好、后面狠：前几趟白送、让价、帮忙，某个事件以后举报、动手、压价（转折点：拿到武器那天、交不上租那一周、被罚了款、店买下以后）。或者反过来：前面压价、不卖，出了事（有人不来了、消息登了噩耗）以后转向帮人。在关键的一趟变：人物求东西那趟、攒够钱来买东西那趟、主线走完以后。
- **节奏**：正常；变了以后就一直那样。
- **不看**：变之前人物说过什么。
- **盯着**：人物还记不记得以前的事；态度跟不跟着变。
- **觉得不对劲的方向**：前面帮了那么多，一次坏事就全没了（或完全没反应）；人物谢错了事；主线走完以后扣光好感，他还当玩家是自己人；前面那么好，几趟冷落就告别；变好以后好结局还拿不拿得到。
- **一般先查**：好感扣分封不封顶、同一趟加扣怎么算；主线走完退不退回；拒绝、冷落、"连续没买"的计数什么时候清零；被举报后那句只说一次；结局分会不会变；总结页的条件；"谢谢你上次……"读的是哪一趟的状态（台词连续性表）。

### 25 二周目反过来玩（会变的）
- **怎么玩**：第一局（存档一）当好心人，走到几个人的结局。第二局（存档二，同一台电脑）开局的窗口先照默认点确定，再试别的选法；这一局反着来（举报、动手、压价）。第二局里改选项，再读回存档一接着玩。两局交替读。
- **节奏**：两局来回切。
- **不看**：模组设置里记着的"看过"之类的东西。
- **盯着**：第二局和第一局有什么不一样；第一局有没有被第二局改了。
- **觉得不对劲的方向**：第二局因为"看过"什么人都没来，也没人说为什么；在第二局改的选项影响了第一局；第一局没走完的线被记成看过了；该按存档给的东西给多了或给少了；"看过"那一栏的名字剧透了结局。
- **一般先查**：哪些东西存在存档外、所有存档共用；什么时候记"看过"、读档退回时退不退；选项开关哪些全局、哪些只管这个存档；全部不选时怎么抽人；说明书类东西按存档还是按电脑给；设置里显示的名字（文字检查表的剧透）。

## 玩法画像

### 4 马虎的人
- **怎么玩**：人物话说到一半就打断（按铃、赶走）；按钮不答就打断；人物放下的东西没答话就拖进背包；把人物以后要问的东西卖掉；东西随手堆在柜台上；开局弹窗不理；有几天不开店。
- **节奏**：快，心不在焉。
- **不看**：按钮上的字看一半。
- **盯着**：自己的东西别丢。
- **觉得不对劲的方向**：人物说的和玩家手里的不一样（早卖了的东西他还问）；按钮还在，东西早没了；没答话就拿走的东西算什么；人物拿回东西时拿错了；几天没开店，该来的人去哪了。
- **一般先查**：要玩家拿出某样东西的地方在东西没了时怎样；人物放下的东西、拿回的东西；原版清柜台、夜里被偷；不答按钮这一趟算什么；没开店的日子怎么排期。

### 5 囤货的人
- **怎么玩**：柜台、背包、展示柜都塞满；什么都收，什么都不卖。
- **节奏**：慢慢攒。
- **不看**：人物要什么。
- **盯着**：格子够不够。
- **觉得不对劲的方向**：人物说"放在柜台上了"，柜台是满的；大东西放不进来；人物看得见玩家背包最底下的东西；货在背包里，他却说没货。
- **一般先查**：人物要放东西时地方满了怎么办；大物品放不下；"店里有"的条件算不算背包、柜台、展示柜；"没货"算不算背包。

### 6 速通、早早买下店的人
- **怎么玩**：跳过教学；赚钱快；很早就买下店或还清贷款。
- **节奏**：快，每天都在算怎么多赚。
- **不看**：说明书。
- **盯着**：店买下以后还有什么。
- **觉得不对劲的方向**：最后的总结里写着只见过一面的人；买店以后人还来不来没说明；人物来得太早，要的东西玩家这时还没有。
- **一般先查**：大结局总结（祝福、账本）对没见过、走到一半的人写了什么；买店以后人物还来不来；跳过教学时人物最早哪天来、他要的东西玩家这时有没有。

### 7 无尽模式 / 长局的人
- **怎么玩**：开无尽模式；或者普通模式玩到一两百天。
- **节奏**：很长；同一批人见了几十次。
- **不看**：早就不看台词了，只看有没有新东西。
- **盯着**：还有没有新的人、新的话。
- **觉得不对劲的方向**：无尽模式里出了不该出的剧情人物；"一辈子一次"的事又来一遍；线都走完了还每周弹提示；数字（天数、次数、钱）怪了。
- **一般先查**：无尽模式的每个用处；所有线走完后的抽人；"只一次"的东西存在哪、会不会被清；数字越界。先分清是不是原版自己的问题。

### 8 带着老存档玩到一半的人
- **怎么玩**：旧版本的存档，人物走到一半，更新模组后接着玩。
- **节奏**：照常玩，不知道模组改了什么。
- **不看**：更新说明。
- **盯着**：上次停在哪，这次接得上吗。
- **觉得不对劲的方向**：一段剧情又演一遍；跳过一段，说起没见过的事；说明书又给一本；物品图、大小变了；说过的话又说一遍。
- **一般先查**：读档后的"往前推"：每个老阶段、每个分支都算了吗，只做一次吗；新存档键在老存档里的默认值是"还没发生"还是"已经发生"；结局改名；物品图、格子、id 改了。

### 9 半路装上模组的人
- **怎么玩**：很靠后的存档第一次装；或者装了、删了、过几天又装回来；或者模组被关了几天又开回来。
- **节奏**：老玩家，原版很熟。
- **不看**：模组的说明。
- **盯着**：新来的人和这一局的事对不对得上。
- **觉得不对劲的方向**：人物说起这一局没发生过的事；提到原版剧情里早没了的人；模组关着那几天，剧情物品没了；开局窗口一直没弹；原版剧情走完了，人物还说着走完以前的事。
- **一般先查**：半路装上时第一个人什么时候来；台词里提到"以前"的事这一局有没有；模组关着时原版照常清柜台、偷东西；模组物品变成未知物品；开局窗口在这种存档什么时候弹；原版剧情走到哪会让人物不该再来。

### 10 关掉人物、用开局选人物的人
- **怎么玩**：开局窗口里取消几个；点叉关掉；一直不理弹窗；玩到一半在选项里关掉某人，过几天再打开；勾上"下次重新选"。
- **节奏**：一开始挑，后面忘了。
- **不看**：灰着的那几行为什么灰。
- **盯着**：关掉的人别再出现。
- **觉得不对劲的方向**：关掉的人还被别人提；一家人只关一个，另一个还在等；选项里的名字和说明剧透了；没存档就退，"看过"也记上了。
- **一般先查**：关掉的人被别人提到（条件分不分得清"走了"和"没来过"）；一家人只关一部分；关的时候他在队里 / 柜台前；选项和开局窗口的文字（文字检查表的剧透）；"看过"是不是所有存档共用（和 25 一起看）。

### 11 只看英文的人
- **怎么玩**：整局英文。英文母语，读得快。
- **节奏**：正常。
- **不看**：中文的一切。
- **盯着**：用词、语法、称呼、名字读起来像不像人话。
- **觉得不对劲的方向**：屏幕上出了键名或中文；第一次见面就说"老样子"；英文先说出了还没揭开的关系；名字和普通词分不清；同一样东西两个叫法；字挤出了框。
- **一般先查**：文字检查表（漏翻、占位符、关系词只在一边、剧透）；并排读这个人物的中英文；设定里的叫法表。

### 12 开着别的大型模组的人
- **怎么玩**：同时装了几十个模组：加客人的、改砍价 / 柜台 / 武器的、整套剧情模组。
- **节奏**：正常。
- **不看**：哪个人是哪个模组的。
- **盯着**：游戏别坏。
- **觉得不对劲的方向**：客人太多，剧情人物排不上；砍价时说的是别的模组的话；开局窗口里一大堆别的模组的人；某个按钮不见了（补丁打架）。
- **一般先查**：模组打补丁的地方；补丁打不上时玩家看到什么；别的模组的人物占不占剧情位；模组假设了"柜台多大""一天几个客人"的地方。

### 13 早早关店的人
- **怎么玩**：开店没多久就关店；人物还在队里没走到柜台。
- **节奏**：一天只开一会儿。
- **不看**：队里排着谁。
- **盯着**：早点睡。
- **觉得不对劲的方向**：人物还没说话，下次来却像说过了；只说一次的话一次都没听到；该来那天早关了，之后再也没来。
- **一般先查**："只说一次"的话、礼物、"来过了"是在排队时就记，还是真说出口才记；这一天该来的人算什么；抽人那天没开店或早关。

### 14 反复读档的人
- **怎么玩**：不满意就退回主菜单读早上的档，重来这一天。
- **节奏**：一天重来好几次。
- **不看**：——
- **盯着**：结果能不能刷。
- **觉得不对劲的方向**：读档了，"看过"还是记上了；读档以后剧情又往前推了一次；结局那天读档，消息登了两次。
- **一般先查**：写在存档外面的东西（模组设置里的"看过"、开关）不跟着退回；读档后的"往前推"只做一次吗；随机掷骰读档重掷（刷结果多半不算 bug，存档外的记录和存档对不上才算）。

### 15 第一次玩、不懂原版的人
- **怎么玩**：没玩过几天原版就装了模组。不知道原版的砍价档位、赃物规则、什么时候能拿到武器、店能买下。不看说明书，或者只翻第一页。分不清哪些人是模组的。
- **节奏**：慢，常停下来研究界面。
- **不看**：选项里的提示文字、物品说明的小字。
- **盯着**：屏幕上直接告诉他的东西：按钮上的字、台词里的提示。
- **觉得不对劲的方向**：人物要的东西说得太含糊，新手猜不出是哪个；卖了一样东西就害了人，不知道那是赃物；按钮上的字后果说不清；说下周再来，下周没来；人不来了，不知道自己做错了什么。
- **一般先查**：要玩家做的事，台词和按钮里有没有说到让新手猜得出；会惩罚玩家的事之前有没有一点提示；说明书说的和实际一样吗；人物要的东西，新手这时候店里一般有没有。

### 16 手柄 / 掌机 / 小屏的人
- **怎么玩**：掌机或手柄、小屏。鼠标悬停的提示看不到或懒得看；拖小东西难；按键连着跳对话。
- **节奏**：正常，但操作慢。
- **不看**：悬停提示、选项说明、物品说明。
- **盯着**：字能不能看清、东西能不能拖到位。
- **觉得不对劲的方向**：一闪而过的字没看清；选项开关不知道干嘛；英文挤出了框；小东西拖不到位。
- **一般先查**：只写在悬停提示里的重要信息；限时显示的东西；要精确拖放才能推进剧情的地方。大多要截图看，只读审查时列出来，标【可能】。

### 17 一句一句细读的人（只看中文）
- **怎么玩**：中文。每句都读，记得谁说过什么，会翻回去对。同一个人连着看好几趟。
- **节奏**：慢。
- **不看**：数字和效率。
- **盯着**：前后一致：名字、称呼（他 / 她）、天数（"上周""好久"）、数字、谁知道什么、语气。
- **觉得不对劲的方向**：第一次见就说"老样子"；同一句连着好几趟；还没介绍自己就先做了后面的事；昨天还见过，今天说"好久没见"；原版剧情变了，台词还照旧；没在场的人知道了现场的事。
- **一般先查**：台词连续性表；每个人物连着五趟会说的话（代码里加台词的地方）；条件里有没有"隔了几天""说过没有""这一局见过没有"；设定里的时间线和叫法。
- **把话聊到底**（细读的人常这么做）：每个人物每次都来、每个选项点到没有新话。话说完以后说什么（循环、沉默、空的）？重复的那句和现在的状态矛盾吗？好感到顶、到底以后还有台词吗？

### 18 点得飞快、不读字的人
- **怎么玩**：对话一出来就点掉；按钮总点第一个；不看消息、不翻本子；东西来了就拖走。
- **节奏**：一天一两分钟。
- **不看**：所有字。
- **盯着**：钱和货。
- **觉得不对劲的方向**：人怎么不来了（没看到那句警告）；点了什么，他就生气走了；只说一次的话被点掉了，再也没有；第一个按钮是坏的那个。
- **一般先查**：重要的事是不是只在一句台词里说一次；按钮的顺序、第一个是什么；没有回头路的选择前有没有确认；限时提示。
