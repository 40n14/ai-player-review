# 修一个问题

> [PRK language] 交付用项目设置的语言（默认中文）。英文交付的标题和标记照工具包 docs/report-format.md 的 English 列。

这份说明同时给两种 AI 用：
- 工具包派出去的 AI（页面上点了「让 AI 直接修」）；
- 你自己窗口里的 AI（你对它说"照待修清单修"）。

两边拿到的东西一样，交回来的格式也一样。

<规矩>
- **只修清单里指定的这一条**（或负责人点名的那几条）。别的看着不顺眼的地方，写进下面的「顺手看到的」，不要动。
- **改得越少越好**：能改一行不改十行。不重写、不顺手整理、不改格式。
- 先读这个游戏自己的规矩：项目文件夹里的 `CLAUDE.md`（如果有）、项目设置的 `projectRules`、`rulesFile`。和这份说明冲突时，以游戏自己的规矩为准。
- 不许读、改、列、搜：{{NEVERREAD}}。
- 修之前先把「出处」那几行打开，确认原文还是清单里写的那样。不一样了（别人已经改过），**不要修**，在「修完填这里」写"原文已经变了"，停下。
- 改完自己核一遍：照这一条的「怎么遇到」（有「测试里怎么复现」的也照它）能走通的就走一遍（只读、能在代码里推的推一遍）；要进游戏才知道的，写清要怎么测，不要假装测过。
- 不编：没改的不写改了，没核的不写核了。
</规矩>

<要修的>
清单文件：{{LIST}}
这一条：{{ITEM}}

{{ITEM_BODY}}
</要修的>

<背景笔记>
清单里「背景笔记」那一节是之前做过的人留下的话（哪些地方连着、哪里容易改坏）。先读它。你也可以加一句，给下一个人看，一句就够。
</背景笔记>

<交回来>
做完以后，在清单文件 {{LIST}} 里这一条下面的「修完填这里」写上（照原样的格式，别的条目不要动）：

```
- 改了：`文件:行`：一句话说改了什么（改了几处就写几行）
- 自己核过：怎么核的、结果
- 要进游戏看的：（没有就写"没有"）
- 没把握的：（没有就写"没有"）
- 顺手看到的：（没有就写"没有"）
```

然后把这一条标题前面的 `[ ]` 改成 `[x]`。{{RETURN_NOTE}}
最后用一两句话说你做了什么。
</交回来>
