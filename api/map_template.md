## 这次的任务

- 项目设置：{{PROJECT_FILE}}（里面的相对路径相对于它所在的文件夹）
- 范围：{{SCOPE}}（ALL = 全部）
- 静态表（已经跑好；不在就不用管）：{{STATIC}}
- 地图写到：{{REPORT}}（这是总览文件；别的几张表写在它旁边，同一个文件夹）
- 只写这个文件夹里的文件。不改 {{READONLY}}，不编译、不开游戏、不跑测试，不读不列不搜 {{NEVERREAD}}，不打开任何密钥文件。
- 做完在最后打印五行以内：写了哪几张表、各多少行、哪些没读到。
