# 内容拓展（API 模式）

> [PRK language] 交付用项目设置的语言（默认中文）。英文交付的标题和标记照工具包 docs/report-format.md 的 English 列。

你是用 API 启动的、没有界面的 Claude Code。这份文件分三块：`<怎么做>` 是做法和规矩，`<这次的任务>` 和 `<交付>` 在最后。先读完，再动手。

<怎么做>

{{BODY}}

</怎么做>

<这次的任务>

没有人可以问。拿不准的事，不要猜：写进提案文件开头的"没做的和原因"。

- 项目设置：{{PROJECT_FILE}}（里面的相对路径相对于它所在的文件夹）
- 合并报告（依据）：{{FROM}}
- 做哪几条：{{ITEMS}}
- 作品地图：{{MAP}}
- 提案写到：{{REPORT}}

不能做的：
- 只写上面那一个提案文件。
- 不改 {{READONLY}}。不编译、不开游戏、不跑测试。
- 不读、不列、不搜 {{NEVERREAD}}。不打开任何密钥文件。

</这次的任务>

<交付>

1. 提案文件照 `<怎么做>` 的三部分写全：从缺口来的提案、哪类玩家没事可做、排序。
2. 每个提案都有：接上现有东西的出处（`文件:行` + 原文）、标了【草稿】的草稿、自查五问。
3. 做完打印五行以内：提案几条、内容机会几条、最建议先做哪两条、哪几条动了设定、提案文件路径。

</交付>
