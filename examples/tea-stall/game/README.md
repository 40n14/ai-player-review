# 茶摊（虚构的例子游戏）

这是给审查工具包做演示用的假游戏。没有可以运行的程序，只有设计、数据和文本。

## 一天怎么过

1. 早上看昨天的小结。
2. 摆摊。茶摊有两个座位（`data\settings.json` 的 `stall.seats`）。
3. 客人一个一个来。每位客人说一两句话，点一样东西。
4. 玩家有三个按钮：**照价卖**、**少收一点**、**不卖**。
5. 客人走。收摊。
6. 夜里看账本：今天赚了多少、谁来过。

一局 7 天。第 7 天收摊以后出结局。

## 桌上和货架

东西在 `data\items.json`，图在 `images`。

- **货架**：茶在货架的格子里。玩家点格子就拿起来（按整格判定，`data\settings.json` 的 `shelf.hit` = `cell`）。
- **桌上**：客人送的东西留在桌上。玩家点它，收进柜子。点在图的透明处不算点中（按图的形状判定，`table.hit` = `pixel`）。
- 收摊时，桌上还没收的东西会被扫掉（`table.sweepAtClose`）。
- 客人头上的提示图标只是给玩家看的，点它没有反应（`hints.clickable` = `false`）。

## 客人

- **阿婆**（`granny`）：每两天来一次，要一壶茉莉。钱不多。连着两次被"不卖"，她就不再来（第一次被拒绝时她会说一句警告）。少收过她两次以上，第 7 天她会送一包自己晒的花。
- **老周**（`zhou`）：第 2、4、6 天来，要最便宜的粗茶。话少。第 6 天他会说自己是逃兵，问能不能在摊子后面躲一晚。玩家可以答应、拒绝，或者去报官。
  - 设定：老周的来历在第 6 天以前不能让玩家知道。
  - 答应：第 7 天他留下一枚旧铜扣。拒绝：他走了，没有后话。报官：第 7 天早上的小结写"昨夜有人被带走"。

## 结局

- 好结局：阿婆送了花，而且老周没有被带走。
- 普通结局：别的情况。
- 阿婆第 7 天说的话要看老周怎样了：他被带走，她说一句冷话；否则说家常。
