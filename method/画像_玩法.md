# 玩法画像（续）（32–44）

画像库的一部分。写法、三层用法（通用层 / 项目对照层）、别的类在哪：见 `画像.md` 开头和 `画像_索引.md`。
同一个作品，换一种操作习惯去走。和 `画像.md` 里的 4–18、29–31 是一类：决定玩家**怎么操作**。走的时候叠在善恶画像或一条线上。

每个画像多两行：**适用**（什么样的作品才派他）和**只读代码能做到多少**（哪些能定、哪些只能标【可能】）。「出处」里的 [P…] 编号在`docs/references.md`；写【推断】的是没有出处、推出来的。
这些画像是照公开资料整理的，"扮成他能查出什么"多是推断，还没在真作品上试过。

## 32 配装党（钻机制的人）（玩法）
- **适用**：有装备、技能、加成、卡组、天赋这类"能搭配"的系统的作品。没有可叠加的数值就不派。
- **怎么玩**：把每条加成的说明读一遍，再去找最划算的搭配。同一类加成叠到最多；百分比加成和固定加成混着叠；找"触发再触发"的连锁；只堆一个属性堆到头；专挑说明写得最含糊的那件来试；把最贵、最后期的那件也算进去。
- **走法**：先列加成表（来源｜说明上怎么写｜代码里怎么算｜能不能叠｜上限）。再两两组合、三个组合，算结果。
- **节奏**：慢。在菜单里的时间比在玩的时间长。
- **不看**：剧情、外观。
- **盯着**：说明上的数字；实际算出来的数字；有没有上限。
- **觉得不对劲的方向**：说明写 +10%，是乘还是加说不清；两件叠起来比写的大得多（或其中一件白装）；堆到某个值以后变成负数、无敌、零消耗；有个属性加了没用（代码里没人读它）；一种搭配强到别的都不用选。
- **一般先查**：算伤害 / 价格 / 概率的公式；加成的叠加顺序；有没有夹上下限；每个属性在代码里有没有被读到。
- **只读代码能做到多少**：说明和公式对不上、没人读的属性、没上限：能定。"强到破坏平衡"：算式能定，算不算问题让负责人定。手感：做不到。
- **出处**：[P2] 把"爱分析数值规则来优化角色"单列为一个动机；[P3] 里有爱找组合的一型和爱证明自己的一型；[P7] 说玩家会把游戏当优化题，直到找出最省力的打法。

## 33 给自己加规矩的人（挑战自限）（玩法）
- **适用**：有"可选的力量"的作品：能杀可不杀、能买可不买、能升级可不升级、能带队友可不带。
- **怎么玩**：开局定一条规矩，全程守：不杀任何人；游戏里的钱一分不花；不升级、不拿任何可选强化；只用开局那件装备；不带队友；不存档。碰到守不住的地方就停下来记。
- **走法**：每条规矩列一张"被迫破戒表"：哪一步不破戒就过不去。再看计数为 0 时的文本和结算。
- **节奏**：慢、谨慎。
- **不看**：正常路线的奖励。
- **盯着**：有没有一步是强制的；作品认不认这条规矩（成就、结算、台词）。
- **觉得不对劲的方向**：教程强制买 / 杀 / 升级一次，规矩开局就破了；过场里替玩家杀了人，算在玩家头上；"不杀"的成就因为陷阱、队友、环境伤害算成了玩家杀的；结算写"你击败了 0 个敌人"，后面的句子不通；等级或钱是 0 时，除法出错或门槛过不去。
- **一般先查**：强制的教学步骤；击杀 / 花费 / 等级的计数在哪加、算谁的；结算页带变量的句子在 0 时的样子；用"至少有 N"做门槛的地方。
- **只读代码能做到多少**：强制步骤、计数归属、0 值文本：能定。"打不打得过"：数值上不可能赢的能定，其余做不到。
- **出处**：[P35] 把"尽量少拿资源通关"列为速通里的一类限制；[P37] 摘要：不杀、最低等级、只用初始武器这类玩法在社区里很常见。专门的研究**没查到**。和 28 的区别：28 是拒绝提示；这个是守一条自己定的规矩，查的是"强制"和"0 值"。

## 34 暂停党（玩法）
- **适用**：实时进行、又能暂停或开菜单的作品（即时战略、带暂停的经营、动作 RPG）。回合制不派。
- **怎么玩**：一有事就暂停。暂停着下命令、排队列、翻菜单、换装备、存档。在过场、对话、读条、倒计时、动画播到一半时按暂停。暂停很久再回来。暂停时改设置、调速度。有照相模式的，开着照相模式把镜头飞远。
- **走法**：列所有"会自己走的东西"（计时器、冷却、读条、增益剩余时间、NPC 日程、自动存档）。每个问：暂停时它停不停。
- **节奏**：走走停停，一半时间是停的。
- **不看**：实时的压力。
- **盯着**：暂停时什么还在动。
- **觉得不对劲的方向**：暂停了，倒计时还在走（或增益还在掉时间）；暂停时能做的事比不暂停时多，白占便宜；暂停时下的命令恢复后丢了；在对话 / 过场里暂停后回不来；暂停菜单里存的档，读回来状态不对；照相模式的镜头碰到了触发区，事件提前发生了。
- **一般先查**：计时用的是受暂停影响的时间还是真实时间；暂停时哪些输入还收；暂停和对话 / 过场 / 读条的状态怎么叠；暂停中存档写了什么。
- **只读代码能做到多少**：计时器用哪种时间、暂停时收哪些输入：能定。引擎的默认行为：【可能】。
- **出处**：【推断】。旁证：[P12] 建议让玩家能在暂停时下动作，说明"暂停着玩"是被认可的玩法。

## 35 挂机的人（放着不管、改系统时间）（玩法）
- **适用**：所有作品（挂在某个界面上）。有真实时间系统的（离线收益、每日刷新、真实时钟）多查一层。
- **怎么玩**：开着游戏去吃饭、睡觉。停在标题页、对话中间、商店界面、战斗里、暂停菜单各一次。有离线收益的：关掉一晚、一周、一年再开。把系统时间往后调一天，再调回去。掌机合盖休眠再打开。
- **走法**：列所有按真实时间算的东西（离线收益、体力回复、每日刷新、限时活动、自动存档、超时）。每个代入：0 秒、一晚、一年、时间倒退。
- **节奏**：人不在。
- **不看**：——
- **盯着**：回来以后多了什么、少了什么、过期了什么。
- **觉得不对劲的方向**：挂在某个界面上，后台的事件照常触发，回来人已经输了；离线收益没上限，一年不上线直接毕业；时间往回调以后，冷却变成几万年（或每日奖励能反复领）；限时的事在休眠时过期了，没提示；开得太久，计数器越界；自动推进的对话把只说一次的话放完了。
- **一般先查**：离线时间差怎么算、有没有上限、负数怎么办；用本机时间还是服务器时间；哪些界面会让世界停下；自动推进的对话；累加型计数的类型和上限。
- **只读代码能做到多少**：时间差的算法、上限、负值：能定。长时间运行稳不稳、漏不漏内存：做不到（那是浸泡测试，要真跑）。
- **出处**：[P40] 摘要：放置类会在玩家回来时按离开的时间补发收益，很多人一天回来好几次；[P20] 测试种类里有"浸泡测试"：长时间开着不动，看会不会出问题。改时间那部分是【推断】。和 7 的区别：7 是游戏里的天数多，这个是真实时间长。

## 36 有多少花多少的人（玩法）
- **适用**：有钱 / 资源、又有"到时候必须付"的东西（房租、维护费、过路费、复活费、押金）的作品。
- **怎么玩**：钱一到手就花光，消耗品一拿到就用掉，从不留底。升级、装饰先买。该付账那天身上是 0。能借就借到顶。
- **走法**：列所有"必须付"的点和所有"保底进项"。每个必付点代入"余额 0、库存 0"。
- **节奏**：快，不做计划。
- **不看**：以后要用什么。
- **盯着**：现在能买什么。
- **觉得不对劲的方向**：到了必须付钱的一步，没钱也没有别的出路；破产没有后果，也没有说法；借的钱不用还；余额变成负数还能接着买；用光了的消耗品，后面有一步非它不可，又没处再拿。
- **一般先查**：每个扣钱的地方是先查余额还是先扣；余额不够时的分支；破产 / 欠债的流程；必需消耗品的补给来源；有没有不花钱的保底进项。
- **只读代码能做到多少**：分支有没有、余额会不会负：能定。"会不会太紧"：做不到。卡死的条目和软锁走法的对在一起。
- **出处**：[P1] 有一型玩家偏爱即兴、反应式的玩法，不爱提前算很多步；推成"不留底"是【推断】。是 5 囤货的反面。

## 37 只走主线的人（玩法）
- **适用**：有主线 / 支线之分的作品。
- **怎么玩**：只做标了主线的事。不接支线、不逛、不和非必要的人说话、不捡不顺路的东西、不练级。能跳的过场都跳。
- **走法**：先列主线必经步骤。每一步问：它要的等级、物品、情报、人物，只靠主线拿得到吗。
- **节奏**：快，直奔下一个标记。
- **不看**：支线、图鉴、可选对话。
- **盯着**：下一个主线标记。
- **觉得不对劲的方向**：主线某一步要的东西只有支线给；主线台词提到只在支线里认识的人，像是老熟人；只靠主线的经验，到后面数值上打不过；结局总结里夸了没做过的事；主线把话说一半，另一半在可选对话里。
- **一般先查**：主线每步的前置条件；主线文本里的人名、物名第一次介绍在哪；主线给的经验 / 钱总量对后期门槛；结局总结的条件。
- **只读代码能做到多少**：依赖、首次介绍的位置：能定。"会不会太难"：数值算得出"不可能"的能定，其余【可能】。
- **出处**：[P5] 有一种特质只想尽快完成最终目标，只看必做的；[P1] 有一型玩家偏爱被安排好的、有主线故事的体验。和 6 的区别：6 是"赚得快、早买店"；这个是"可选的一概不碰"。

## 38 拖着不推进的人（龟缩 / 只逛支线）（玩法）
- **适用**：有主线推进点、或对手会行动的作品（RPG、策略、生存、经营）。
- **怎么玩**：主线停在某一步，去干别的，几十个小时不回来。策略里只守不攻，把基地修成铁桶，等。别人催也不动。能等就等，看世界自己会不会变。
- **走法**：列每个主线停靠点。每个点问：停在这里时，什么在涨、什么在等、什么会过期。
- **节奏**：很慢，没有目标。
- **不看**：催促的提示。
- **盯着**：我不动的时候，世界动不动。
- **觉得不对劲的方向**：主线说"十万火急"，拖一年也没事，台词还是那句；停在某一步时，资源无限涨（守着就能刷）；对手永远攻不进来，也不变强，游戏结束不了；支线的门槛其实是主线进度，没人说；主线停着时，角色每次重复同一句催促；拖久了，限时支线悄悄没了。
- **一般先查**：有没有任何随时间升级的压力；每个停靠点上重复说的台词；停着时还开着的进项；支线对主线进度的依赖；对手有没有"打破僵局"的逻辑。
- **只读代码能做到多少**：有没有时间压力、进项关没关、台词重不重复：能定。对手实际打不打得进来：【可能】。
- **出处**：[P5] 有一种特质回避危险、囤生存资源；[P7] 说低风险的小回报会被玩家无限刷。上一轮把"谨慎的人"判了低；这次收，是因为"一直拖着"能查出别人不查的东西：停着时还在涨的数。

## 39 同时接满任务的人（支线清理党）（玩法）
- **适用**：能同时挂多个任务 / 委托 / 订单的作品。
- **怎么玩**：见任务就接，一个不交，攒到最多。同一个人身上挂三四个任务再去找他。两个任务要同一样东西，只拿一件。先把所有支线清完再碰主线。
- **走法**：列任务表（任务｜要哪个人｜要哪样东西｜要哪个地点｜改哪些状态）。找共用同一个人、物、地点的任务对，一对一对走。
- **节奏**：慢，清单式。
- **不看**：轻重缓急。
- **盯着**：任务列表、任务标记。
- **觉得不对劲的方向**：一个人身上两个任务抢同一个对话入口，只出得来一个；交一件东西，两个任务都算完成（或都不算）；一个任务把另一个任务要的人带走了；任务列表装不下、排序乱；支线全清以后等级太高，主线台词还把玩家当新人；任务甲的奖励让任务乙没法做。
- **一般先查**：对话入口同时满足多个条件时选哪个；任务物品是"有就行"还是"交掉"；任务之间互相改的状态；任务数量上限；列表界面有没有滚动。
- **只读代码能做到多少**：优先级、互相改状态、数量上限：能定。列表显示：【可能】。
- **出处**：[P5] 有一种特质要把每件事都勾掉；[P21] 说测任务要按状态和转移来排，特别提到条件之间的副作用。和 26 的区别：26 问"拿不拿得到"；这个问"同时挂着会不会打架"。

## 40 每件事都失败的人（摆烂）（玩法）
- **适用**：有成功 / 失败判定的作品（战斗、限时、考核、小游戏、经营指标、养成）。
- **怎么玩**：每个能输的地方都故意输：让倒计时走完、每场都打输、小游戏交白卷、指标全不达标、该照顾的不照顾。连着输很多次。
- **走法**：列所有判定点。每个点走失败那一支；再走"连输三次、十次"。
- **节奏**：正常，不努力。
- **不看**：怎么赢。
- **盯着**：输了以后还能不能接着玩。
- **觉得不对劲的方向**：失败那一支没写，直接当成功处理；输了没有任何话，像没发生；输了以后任务挂在那儿，不能重来也不能放弃；连着输，惩罚一直叠，叠到没法玩；失败的台词假定了"你尽力了"；输掉的奖励永远拿不到，没提示。
- **一般先查**：每个判定的失败分支通到哪；任务每个阶段有没有失败 / 放弃的出口；失败次数的计数和上限；失败后的重试入口。
- **只读代码能做到多少**：分支有没有、通到哪：能定。"惩罚重不重"：【可能】。
- **出处**：[P21] 说任务每个阶段至少要有一条成功路和一条放弃或失败路，软锁和挂着的目标多出在失败路上。和 28 的区别：28 是不配合（拒绝）；这个是配合了但做不成。

## 41 同一关死很多次的人（玩法）
- **适用**：有死亡 / 重来 / 存档点的作品（动作、平台、生存、roguelike、有战斗的 RPG）。
- **怎么玩**：同一个难点连死二十次。每次从存档点跑回来。死在存档点旁边、死在过场刚结束、死在拿到东西还没存的时候。死够了去找"跳过""降难度""帮一把"。
- **走法**：列每个存档点到下一个存档点之间有什么（多长、有没有不能跳的过场、有没有一次性的东西）。每段问：死一次丢什么、重来要重看什么。
- **节奏**：反复，越来越没耐心。
- **不看**：剧情。
- **盯着**：重来要多久；丢了什么。
- **觉得不对劲的方向**：每次重来都要重看同一段不能跳的话；死了以后复活在必死的位置，循环；死之前拿的一次性东西没了，也拿不回来（或者反过来，死一次多拿一份）；消耗品死后不还，越死越打不过；中途不能改难度；失败再多次也没有任何帮助或跳过。
- **一般先查**：存档点 / 自动存档在哪写；复活点怎么选；死亡时哪些状态回滚、哪些不回滚；过场能不能跳、看过以后能不能跳；难度能不能中途改。在存档点外和重来菜单各改一次难度或帮助，再查这场从哪一刻开始按新设置结算，以及重开是否还记得【推断】。
- **只读代码能做到多少**：回滚了什么、过场能不能跳、难度能不能改：能定。条件写明的死亡循环：能定。"难不难"：做不到。
- **出处**：[P11] 的挑战类做法里有"跳过""帮一把""放慢""常存档"几项；[P12] 建议能中途改难度、能跳过不是核心的玩法。

## 42 每次只玩几分钟、随时要走的人（玩法）
- **适用**：所有作品；手游、掌机上的更要派。
- **怎么玩**：每次只玩五到十分钟。随时会被打断：电话来了、到站了。直接关掉，不走存档流程。在对话中间、战斗中间、读条中间、存档正在写的时候关。下次打开，从哪接上就从哪玩。
- **走法**：找出"最长的不能存、不能停的一段"。列每个强制连续段（过场 + 战斗 + 过场）。每段问：中间关掉，回来在哪。
- **节奏**：碎。
- **不看**：长段的铺垫。
- **盯着**：现在能不能走。
- **觉得不对劲的方向**：一段要连着打很久才有存档点；过场中间关掉，回来要从头看；正在写存档时关掉，档坏了；回来以后站在原地，不知道刚才在干嘛；自动存档只在很少的地方；战斗 / 对话里禁止存档，没说明。
- **一般先查**：自动存档的触发点；哪些状态下禁止存档；存档是不是先写临时文件再替换；对话 / 战斗中途的状态存不存；重新打开后的落点。
- **只读代码能做到多少**：存档点分布、禁存条件、写入方式：能定。一段到底多少分钟：只能估，标【可能】。
- **出处**：[P4] 最大的一群玩家只在零碎时间玩，多在手机上；[P52] 说定义玩家时要写清他们在哪玩、会不会被打断，游戏要能随时停、随时接；[P44] 摘要：手游一次会话的中位数只有几分钟。和 13、29 的区别：13 是游戏里早收工；29 是隔了几个月；这个是每次都被打断。

## 43 带着答案来的人（攻略 / 直播 / 旧版本的记忆）（玩法）
- **适用**：有谜题、密码、隐藏条件、"先知道才能做"的步骤的作品。
- **怎么玩**：照着攻略玩，或者看过别人的直播，或者上个版本玩过。直接输密码，不去找线索。直接走到隐藏地点。第一次见面就选"正确"选项。跳过所有教程。照着的攻略是旧版本的。
- **走法**：列所有"答案"（密码、顺序、位置、正确选项）。每个问：代码查的是"输对了"，还是"先看过线索再输对"。
- **节奏**：快，不探索。
- **不看**：线索、铺垫。
- **盯着**：攻略上写的和眼前的一样不一样。
- **觉得不对劲的方向**：没见过线索就输对了密码，后面的台词却说"多亏你找到了那张纸条"；答案是写死的，所有人都一样；跳过了发线索的那段，线索物品还留在世界里没人收；直接走到后面的地点，前面的事件再也触发不了；教程跳了，教程里发的东西也没了。
- **一般先查**：答案是固定的还是每局生成的；验证处查不查"知道线索"的标记；后续文本引用线索场景的地方；教程里发的物品和标记，跳过时补不补。
- **只读代码能做到多少**：这些都写在条件里：能定。
- **出处**：[P4] 有两型人看别人玩比自己玩多；[P34] 摘要：多路线游戏的玩家常常第一遍自己走，之后照攻略走；[P46] 摘要：作品里的秘密很快会被拆出来传开。和巡游包"错序"的区别：错序是把两步对调；这个是脑子里已经有答案。

## 44 改数值的人（修改器 / 控制台 / 改存档）（玩法）
- **适用**：单机作品（PC 上尤其）；有控制台、调试菜单、明文存档的更要派。
- **怎么玩**：用修改器把钱改成九位数、血锁住、时间加速十倍。用控制台刷物品、传送、直接完成任务。手改存档里的数字和标记。改完接着正常玩。
- **走法**：列"正常玩不可能出现的状态"：有任务物品但没接任务；任务完成了但前置没做；数值超上限或为负；唯一物品有两件。每个代进去走。
- **节奏**：快，跳来跳去。
- **不看**：正常的进度。
- **盯着**：作品还撑不撑得住。
- **觉得不对劲的方向**：钱太多，价钱显示挤出框或变成负数；手上凭空有任务物品，对应的角色没反应或者报错；传送跳过了触发区，后面永远等不到那件事；加速以后计时的事件乱了；改过的存档读不出来，不说为什么，直接坏档；发布版里调试菜单还开着。
- **一般先查**：数值的类型和上下限；读档时校不校验、坏了怎么办；条件查的是"有东西"还是"走过流程"；发布版里留着的调试入口和命令。
- **只读代码能做到多少**：上下限、读档校验、调试入口：能定。很多条负责人可能不想管，写"请确认要不要管"。
- **出处**：[P38] 摘要：一项 188 人的问卷发现，多数玩家认可在单机里作弊，说是用来调节心情；厂商赞助的问卷数字不引。读档校验那部分是【推断】。
